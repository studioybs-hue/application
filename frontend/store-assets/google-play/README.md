## 📋 Où les uploader sur Google Play Console

1. **Connectez-vous** : https://play.google.com/console
2. **Sélectionnez votre app** CINÉMARIÉS
3. Menu **"Croissance"** → **"Présence sur le Store"** → **"Fiche du Store principale"**

### 🎯 Section "Éléments graphiques"

- **Icône de l'application** → uploadez `icon-512x512.png`
- **Graphique principal** → uploadez `feature-graphic-1024x500.png`

## 📸 Screenshots (à faire manuellement)

Google demande **2 à 8 screenshots** de l'app sur téléphone. Vous devez les prendre **directement depuis votre téléphone Android** :

### Comment prendre les screenshots
1. Ouvrez l'app CINÉMARIÉS sur votre Android
2. Pour chaque écran à capturer : **Volume bas + bouton power** simultanément
3. Récupérez les screenshots dans `Galerie → Captures d'écran`
4. Transférez sur votre PC (USB ou WhatsApp Web)

### 📱 Écrans recommandés à capturer
1. ✨ **Page Découvrir** (vidéothèque publique avec posters)
2. 💍 **Détail d'un mariage** (poster doré + bouton play)
3. ▶️ **Lecture vidéo** en plein écran
4. 📷 **Galerie photos** d'un mariage
5. 💎 **Page Premium** ou **Profil utilisateur**
6. 📝 **Page Devis** (formulaire de quote)

### ✅ Format accepté par Google
- Largeur : entre 320 px et 3840 px
- Hauteur : entre 320 px et 3840 px
- Ratio : 16:9 ou 9:16 (vertical recommandé)
- Format : JPG ou PNG (sans transparence)
- Taille max : 8 MB par image
